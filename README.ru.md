## Быстрый старт

Клонируйте репозиторий и запустите интерактивный установщик:

```bash
git clone https://github.com/DinomiHaMC/DFishConf.git ~/DFishC
bash ~/DFishC/ins.sh
```

Либо сначала скачайте установщик, проверьте его и только потом выполните:

```bash
curl -fsSL https://ins.dinomiha.ru/dfish -o dfishc-ins.sh
bash -n dfishc-ins.sh
less dfishc-ins.sh
bash dfishc-ins.sh
rm dfishc-ins.sh
```

Всегда указывайте `https://` явно. Запуск через `curl | bash` поддерживается, но скачивание файла безопаснее: код можно проверить, а ошибка `curl` не будет скрыта кодом завершения pipeline.

Установщик интерактивный. Он принимает `y`/`yes` и `д`/`да`; пустой ответ означает «нет». После смены shell перелогиньтесь.

## Состав проекта

| Компонент | Назначение |
| --- | --- |
| `dots/fish/` | Модульная настройка Fish: функции, интеграции и условные алиасы. |
| `dots/kitty/` | Конфигурация и цветовая тема терминала Kitty. |
| `dots/starship.toml` | Настройка prompt-а Starship. |
| `ins.sh` | Интерактивная установка пакетов, конфигов, Fish и опциональных инструментов. |
| `DFetch.sh` | Краткая сводка о Fish/DFishC в стиле fastfetch. |
| `DSort.sh` | Сортировка `~/Downloads` по каталогам для медиа, кода и документов. |

Конфигурация Fish разделена по ответственности: пути, окружение, терминальные алиасы, утилиты, редакторы, пакетные менеджеры, Python, интеграции и запуск. Fish загружает файлы из `conf.d/` в лексикографическом порядке.

## Поддерживаемые системы

| Система | Источник пакетов | Особенности |
| --- | --- | --- |
| Arch Linux и производные | `pacman`, при необходимости `yay` | Установит `yay`, если он выбран и отсутствует. |
| Debian, Ubuntu и производные | `apt` | Некоторые дополнительные TUI-пакеты могут потребовать ручной установки. |
| NixOS | `nix profile` | Также выводится декларативный пример для `configuration.nix`. |

На неопознанной системе можно продолжить без distro-specific установки пакетов.

## Безопасность и поведение

В автоматическом режиме `ins.sh` может установить базовые терминальные программы, zapret, LazyVim, FastCommanderTUI, конфиги и запуск Fish. Ручной режим запрашивает подтверждение для каждого компонента.

Внешние проекты, код которых выполняется при установке, закреплены на конкретных commit-хэшах. Существующие конфиги и скрипты переносятся в:

```text
~/.local/state/dfishc/backups/<дата-время>/
```

LazyVim сначала загружается во временный каталог и заменяет `~/.config/nvim` только после проверки. Содержимое `dots/` копируется в `~/.config/`, а не подключается символическими ссылками.

### Устанавливаемый набор

Точный список зависит от системы, но включает Fish, Git, Neovim, Starship, Zoxide, Fastfetch, LSD, Btop, Bat, Lazygit, Python, Cargo, OpenSSH, Docker и поддержку NTFS. На Arch через AUR дополнительно запрашиваются `lazyssh`, `lazydocker` и `superfile`.

> [!NOTE]
> На NixOS Fish, Docker и shell пользователя лучше включать декларативно в `/etc/nixos/configuration.nix`; установщик выводит готовый фрагмент.

## Работа в Fish

DFishC добавляет пути для локальных бинарных файлов, Nix-профилей, Cargo и Go. При наличии нужных программ он инициализирует Zoxide, Pyenv и Starship, а Fastfetch запускает только в интерактивной сессии.

DFishC сохраняет исходное значение `TERM` терминала, поэтому `nano` не обёрнут и не получает отдельный тип терминала: команда `nano` работает как обычно, с текущим окружением. Команду `kit <команда>` используйте только для программ, которым действительно нужны возможности Kitty.

### Основные команды

| Команда | Действие |
| --- | --- |
| `na`, `sna` | Открыть Nano, либо Nano через `sudo`. |
| `nv`, `snv` | Открыть Neovim с возможностями Kitty, обычно или через `sudo`. |
| `ff`, `mon`, `bt` | Запустить Fastfetch, Btop и Bat/Batcat, если они установлены. |
| `l`, `la`, `lla`, `lt` | Удобные варианты `ls`; при наличии используется LSD. |
| `gc`, `ga`, `gcm`, `gp` | Сокращения для Git clone, add, commit и push. |
| `ai`/`au`, `pacs`/`pacupd`, `ys`/`yupd` | Команды Apt, Pacman и Yay; появляются только при наличии менеджера. |
| `proxy <команда>` | Запустить команду с локальными HTTP/HTTPS proxy-переменными. |
| `DFishC-fetch`, `DFishC-update` | Запустить сводку или обновить клон в `~/DFishC`. |

Выполните `alias` в Fish, чтобы увидеть доступные на этой машине сокращения. Зависимые от программ алиасы создаются только при наличии соответствующей команды.

### Функции

| Функция | Действие |
| --- | --- |
| `ffinder <запрос>` | Открывает поиск Google в новом окне Firefox. |
| `n [путь]` | Открывает Nautilus в текущем каталоге или по указанному пути. |
| `use <путь-или-url>` | Открывает URL и файлы подходящей программой; в каталог выполняется переход. |
| `clean` | Очищает кэши поддерживаемых пакетных менеджеров и логи journal. Перед запуском проверьте реализацию: функция удаляет данные. |

## Сортировщик загрузок

`DSort.sh` при необходимости создаёт `~/Audios`, `~/Pictures`, `~/Videos`, `~/Code` и `~/Docs`, затем переносит файлы из `~/Downloads` по расширению. Всё, что не относится к известным медиа- или кодовым форматам, попадает в `~/Docs`.

```bash
bash ~/DSort.sh
```

## Обновление и удаление

Чтобы обновить клон:

```bash
cd ~/DFishC
git pull
bash ins.sh
```

Единой разрушающей команды удаления нет. Восстановите файлы из `~/.local/state/dfishc/backups/`, при необходимости удалите скопированные каталоги из `~/.config/` и отмените смену Fish login shell или изменения `.bashrc`.

## Участие в разработке

Issues и pull requests приветствуются. Сохраняйте модульность конфигов Fish, а алиасы для необязательных программ делайте условными. Перед отправкой изменений проверьте синтаксис:

```bash
bash -n ins.sh
fish -n dots/fish/config.fish dots/fish/conf.d/*.fish dots/fish/functions/*.fish
```
